# 原生研究紀錄的容量界線

實際美國研究完成後產生 697 個原始 trace 檔案、13,512,407 bytes；舊版 512 檔案上限使後續收集失敗。原始失敗與提案保留，不能把失敗改成成功。

新收集器容許最多 4,096 個檔案，仍逐檔核對 bytes、hash 與路徑。每檔 4 MiB、總計 32 MiB、事件 20,000 的原有界線保持有效；超限直接失敗，不截斷紀錄。

這是「保存紀錄的空間」，不是「可以呼叫更多模型或工具」。A/B 的模型、權限與投入政策仍需另行凍結。

事後取得的 hash 必須標明取得時間，不能冒充失敗前已保存的 producer receipt。舊執行可作明示的恢復診斷；正式完成仍須通過其實際執行與證據驗證。

改善聲明：已修復正常研究紀錄超過 512 檔案時的收集缺陷；研究品質改善尚未證明。
