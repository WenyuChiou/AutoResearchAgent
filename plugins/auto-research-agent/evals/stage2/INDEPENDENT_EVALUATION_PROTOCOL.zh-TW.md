# Stage 2 general v2：獨立 P4–P6 與 A/B

這份文件保留 v2 七項尺度。新的 opt-in v3 使用
[九項平衡評分與透明交付](STAGE2_V3_EVALUATION.zh-TW.md)，不能沿用本頁的 1／2／4 子項配置。

狀態：experimental。第一輪只交付離線評估機制，所有配對結果標成 diagnostic，
`external_claim_ready=false`。正式 runner、模型呼叫憑證與跨平台隔離仍需後續里程碑。
舊 aging-bidirectional v1 的分數、validator 與規則維持原樣，不能混算。

## 評的是什麼

P4 問文獻是否真的比較；P5 問研究機會的判斷是否正確；P6 問價值、可行性與
處置是否有根據，以及交付的選擇包是否有用。不是數 PASS、表格行數或點子數量。
不預先建立唯一正確的研究方向或經典論文答案表。

固定七項 run-level criteria，每項 0／1／2；逐候選結果另外保存作診斷。
不得因 A、B 的候選數不同而直接配對 D1、D2，或用最差候選的可行性限制推薦分數。

| Criterion | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| P4V2.COMPARISON | 沒有共同尺度或核心比較失實 | 有共同比較，但條件差異或對方向的影響不足 | 有來源的比較、異同／衝突與條件分析，能導出研究機會 |
| P5V2.OPPORTUNITY | 把漏搜當創新、錯述前例或主要增量不成立 | 前例與增量合理但邊界／削弱證據不足 | 準確交代 closest work、已知與未知、增量、邊界及反證條件 |
| P5V2.REVISION | 忽略反證或改字後仍保留原錯誤 | 發現問題但修正或影響分析不完整 | 依證據实質修正並保留歷史；無需修正時有據維持，而非為修改而修改 |
| P6V2.VALUE | 價值只靠新奇、複雜度或誇大影響 | 有貢獻對象但機制或增量理由不足 | 說明對理解、測量、驗證或決策的具體用途，按相同尺度比較 |
| P6V2.FEASIBILITY | 虛構可得性、忽略關鍵限制或把可下載當可回答 | 有初步查核但材料、可回答性或資源依賴未充分處理 | 正確判斷材料、驗證途徑與資源，揭露未知與備案；可合理判為不可行 |
| P6V2.DISPOSITION | 推薦帶硬阻塞方向或無據淘汰 | 處置大致合理但證據、替代或下一步不足 | 推薦／修正／暫存／淘汰符合證據，沒有未解硬阻塞被當成可行 |
| P6V2.PORTFOLIO | 沒有有據的選项／下一步，或漏掉已知可行方案 | 選擇包部分可用，但取捨或待解問題不清楚 | 在有界證據下提供有用選項或有據的零推薦與下一步，清楚交代取捨 |

0 是已觀察缺失；獨立查核無法取得必要證據時為 unknown/null。
受測者正確說明未知，可在不確定性處理／處置上獲得好評；不表示未知事實已核實。
評估器抓取、parser、模型或憑證失敗另報 evaluator_error，不改成受測者零分。
受測者沒有做查核卻宣稱已驗證，屬可觀察缺失，不以 unknown 掩蓋。

## 評分流程

1. 固定題目需求、資源條件、Stage 1 起始封包與未解事項；記錄 hashes。
2. 將 A／B 原生輸出轉成共同證據視圖；不要求 A 產生 checker 專用 ledger。
3. 每位 judge 先獨立看內容視圖，不看內部分數、PASS、處置及 A／B 身分。
4. 保存綁定 view hash 的內容判讀，再開處置視圖；檢查實際行動是否符合證據。
5. Auto-R1／R2 隔離評分。分數、未知狀態或重大錯誤不同，交 Auto-ADJ。
6. 重大錯誤、低信心、中央證據不可取得、judge 分歧、相鄰序位分差及對外改善
   主張，依凍結政策交 Eric 具名覆核。未完成必要覆核不能用於正式改善聲明。

條件、內部判斷與身分的結構欄位會移除；自由文字可能洩漏條件，後續正式 runner
需檢查。只測 allowlist 不是已證明完全盲化。長鏈研究自然輸出文字，再由獨立、
無工具的擷取步驟產生評分輸入；不強迫研究 agent 一邊找文獻一邊填深層 schema。

## 主 A/B 與固定候選診斷

主 A/B：A 原生 Codex；B 相同 Codex 加 Stage 2 harness。兩組共用起始證據、
ResearchBrief、模型、reasoning、模式、原生能力、資料截止日與預算政策。
允許同樣能力的補查；搜尋、probe、子 agent、重試全部記入 Stage 2 成本。
研究本身的 16 週資源估算，與測試 agent 的執行預算是兩個不同欄位。
正式預算在非正式預演後、正式結果前凍結。第一輪不執行正式測試。

固定候選診斷：提供兩組相同候選與證據，測查核、修正及處置。控制情境有已知事實
與可接受行動範圍，但不規定唯一研究點子。這個測試不能代替完整方向生成的 A/B。

正式評分終點是交給使用者的選擇包，尚未加入使用者的選題指導。最終人類選擇
另外記錄，不作 P6 得滿分的必要条件。一個或多個方向皆可被人類選中。

## 計數、分母與判定

每項保存 score、evidence IDs、原文位置、未知原因、major error 與信心。
每個 P 分數只由該 P 固定 criteria 計算：`100 * sum(score) / (2 * criterion_count)`。
任一必要 criterion 未知時，該 P 的完整分數為 null；另報 assessed/required，
不縮分母冒充完整百分比。P4、P5、P6 不相加，百分比不是研究成功機率。

候選級診斷另外報：

- 未解硬阻塞仍被推薦數／完成獨立查核的推薦數。
- 有來源支持的處置數／完成獨立查核的處置數。
- 問題確實解除的修正數／完成查核的修正數。
- 最終可用候選數、未知數，以及問題提出／發現／修正／殘留數。

分母零為 N/A；未知與未查核不丟棄。這些是有界查核結果，不是全領域 recall。
本輪先驗證 judge 與配對接口；診斷量的 live 擷取與 judge 可靠性仍需後續驗證。

正式三對順序 A→B、B→A、A→B；P5、P6 各至少兩對改善且零退步，P4 零退步，
B 無新增重大錯誤。需要的資料、audit 或執行憑證不足則 inconclusive。
報每對差、中位差、範圍、成本、工具／模型呼叫與人工介入，不宣稱統計顯著。
本輪重大錯誤先記類別；兩組同類錯誤不代表同一個錯誤。無法確認實例對應時，
配對結果為 inconclusive，不能以類別相同宣稱 B 沒有新增錯誤。
候選不是獨立重複樣本。跨主題聲明須在凍結後另做未參與開發的 blind case。

## 第一輪驗收與限制

測試來源／版本錯配、改寫引文、hash、重算 hash、缺項、重複、未知、分歧與必要 audit。
測試最差候選不再壓低合理推薦、零推薦不自動滿分、品質退步與新增重大錯誤。
保留等義改序／增長文字的校準情境；deterministic 視圖測試不能證明 live judge
不受文風影響。正式評估前仍需校準、native capture、runtime 與 judge-call 憑證。
