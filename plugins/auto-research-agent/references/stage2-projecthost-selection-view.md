# ProjectHost Stage 2 current direction view

Host code binds a project/input/brief to an externally hashed delivery and its actual workflow root. A saved activation and durable frontier are required; configured paths alone never admit an unactivated project. Browser requests supply an opaque project reference, never paths. ProjectStage2SelectionView.read reopens the package and current workflow, verifies active-project identity, and derives existing question/material decision cards.

Unknown source/resource claims remain unknown. Eligible current versions, recorded human selection, planning intake and execution authorization are separate fields. An unselected package is not Stage3 receiver acceptance; this read-only service does not submit a choice or start a model.

This stage adds the package view only. HTTP assets, actual browser acceptance, confirmed UI submission and recoverable selection writes are validated in subsequent changes. Synthetic tests do not establish scientific quality or real human selection.
