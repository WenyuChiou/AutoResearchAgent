# Stage 1 researcher deliverable boundary

This directory is the registered owner for the future Stage 1 researcher-facing
exporter. The exporter is not implemented yet. Its implementation PR must use
the `cli:stage1-deliverable` capability ID, declare `Research Deliverable:
required`, satisfy the contract in
[`../../references/stage1-research-deliverable.md`](../../references/stage1-research-deliverable.md),
and provide a validated, hash-bound Japan pilot manifest.

Package-conformance counts remain separate from P1-P3 scientific-quality
scores. This README reserves the capability boundary; it is not executable
evidence.
