This package describes the local helper in the existing #271 candidate. It
creates no new PR or merge. The helper completes one existing Core source
intent from an original SDK receipt; it never downloads or grants a permit.

The fresh raw-source capture ran eight focused tests in 13.960s: all passed,
none skipped. The capture process returned exit 0 in 16.843s, with identical
source inventories before and after. Tests used actual Core/SQLite and the
public SDK parser on authored HTTP mocks. No external source acquisition,
search, native/model call, scientific judging or full plugin/CI run occurred.

Cases cover available completion plus registry and true ledger reopen; HTTP
503; network timeout with exact receipt bytes as the failure artifact; changed
start URL/version/tool/request; rehashed request or stale time; incomplete
receipt and artifact hash drift; guard refusal before write and after raw
publication; and a receipt outside the fixed materials root. Failures remain
failures or pending. Available text does not verify identity, reading fidelity
or claims. The separately supplied runtime hash is a saved observation binding,
not execution attestation.

The caller still owns current project/candidate/decision/version/permit/budget
and final durable action checks. Core journal effects cannot roll back. A
partial raw save or post-completion owner loss must retain pending/unknown
history and must not be automatically retried or adopted. Production owner
wrapper/source-worker behavior requires separate evidence.

were replaced by explicit placeholders. Its `sanitization` object binds the
untouched original private receipt hash; it is not presented as a raw copy.
Full source inventories, measurements and log hashes were retained. The
complete `stderr.log` and empty `stdout.log` are unchanged captured bytes.
